## 1. The chart dictionary for closed Euclidean tours [T where marked; definitions otherwise]
- **Insertion coin [T, exact].** Inserting node k into tour edge (i,j): cost Δ = a + b − c with a = |ik|, b = |kj|, c = |ij|. Set **x = c/(a+b)** ∈ (0,1]. Then Δ = (a+b)(1−x) = **2q·(a+b)** with q = (1−x)/2 — the corpus's amplitude coin, exactly; G_new = 1/q; SWR = (a+b+c)/(a+b−c) = p/q. Level sets of x are the **confocal ellipses** with foci i, j through k (x = 1/eccentricity): the budget coordinate of a detour is the thinness of its ellipse. u = 1 − x² completes the identity. This is a chart statement (a renaming with exact algebra), not a law — the law question is whether x *decides* anything (§3, Q1c/§5).
- **Port deflection.** At a tour vertex, let θ = interior angle between its two edges and δ = π − θ the deflection; **x_v = cos δ** (straight-through = 1, U-turn = −1). Will's Hyp 1 ("keep the path obtuse") = "keep x_v > 0 at every port"; acute-vertex fraction = fraction of ports with x_v < 0.
- **Two boundary reads and their tolls [T-anchored].** B_deg = ½Σ_k (two cheapest edges at k) is the **pure per-port marginal read** — each port queried alone, no global structure; a valid lower bound. The Held–Karp/1-tree bound dresses the same read with **node potentials π_k — literally a gauge field on ports** — plus one global spanning read (connectivity), still polynomial [T]. OPT − HK is the residue no gauge-dressed abelian read closes: the **anholonomy toll** of the single-cycle constraint. Known [T]: the subtour polytope's fractional points can be locally tour-like at every marginal yet globally disconnected — boundary-null-but-carried, verbatim; and the tour polytope admits **no polynomial-size linear extension at all** (Fiorini–Massar–Pokutta–Tiwary–de Wolf 2012; Rothvoss 2014 lineage) — "no poly abelian ledger carries the global bit," proven at the polytope level.
- **Radix/length reading (Will's framing).** Per-step operative choice = per-port radix (local multiplicity); step count = message length (global multiplicity). A tour is a word in the choice alphabet; the Kraft/coding vocabulary of the 07-15 Collatz layer applies verbatim to the search tree. [id; used in §4.]

## 4. P ≟ NP, pinned in the chart [dictionary-grade; no theorem claimed]
**The map (Will's port/length/depth/budget framing, sharpened).** An instance is boundary data; a witness/solution is an interior path — a word of per-port choices (radix = local multiplicity, length = message length). *Verification* is a boundary read of a supplied path (polynomial = readable). *Solving* is locating the path from the boundary alone. P ≟ NP asks: **is every boundary-readable path boundary-locatable at comparable budget** — does readable imply locatable, or is there genuine anholonomic depth that no polynomially-priced flow-to-terminal compresses?
**Where the barrier theorems sit in the map [T, the pin's substance].** The three classical barriers say, in the chart's own words, where the P/NP bit is *not* readable:
1. **Relativization** (Baker–Gill–Solovay 1975): there are oracles making the answer go both ways, so no proof that treats computation only through its oracle-port response can decide it — **the bit is DtN-null**: not a function of black-box port behavior.
2. **Natural proofs** (Razborov–Rudich 1997): under standard PRGs, no large, constructive — i.e., ensemble/statistical — property separates; **the bit is ensemble-null**: not a moment read, the density-vs-pointwise split verbatim.
3. **Algebrization** (Aaronson–Wigderson 2008): low-degree algebraic extensions of the boundary read still fail — the null-ness survives algebraic completion of the port data.
So the classical meta-theory already asserts: the separation, if provable, is carried in the **pointwise/anholonomic register** — read the interior wiring, not the response operator; and the field's actual positive results (interactive proofs, gate-elimination, the extension-complexity theorems) are path-register arguments. The chart did not discover this; the claim graded here is only that the chart's readable/carried taxonomy **retrodicts the barrier structure exactly**, with the same split (boundary / ensemble / pointwise) the corpus found in the arithmetic register [id — striking, and priced as consonance-with-mechanism-open].
**What is proven vs what is open, in chart terms.** The *boundary-null half is a theorem* for the objects above (extension complexity: no poly abelian ledger carries the tour polytope); the *open half* is locatability: whether some non-abelian polynomial flow nonetheless locates witnesses (P = NP) or the residue is irreducible (P ≠ NP). The chart contributes vocabulary and a place to stand, not leverage on the open half — stated plainly per the two-ledger rule. The calibration sentence is carried verbatim: this problem has consumed serious careers; the realistic near-term product is the discriminating computation, not the theorem.
**The one gradeable [C] this pin licenses:** a budget-native per-instance hardness functional — the measured anholonomy residue (OPT − best gauge-dressed poly read)/OPT of §3, generalized per problem family — with the conjecture that it separates empirically-easy from empirically-hard *instance distributions* (uniform Euclidean TSP: residue ≲ 1%; adversarial/worst-case families: residue bounded away from 0). Could-fail: compute it on a known-hard family (e.g., the 4/3-gap-approaching instances) and on uniform instances; if the functional does not separate, the [C] dies. This is a statistics-of-instances claim, deliberately far below P ≟ NP itself — the honest first rung.
