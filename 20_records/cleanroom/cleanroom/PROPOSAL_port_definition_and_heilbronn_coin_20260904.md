## 1. Definition proposal: a port
A **port** is a place v of ℚ carrying a passive interface whose state is a coin. The three faces already in the record are one object in three charts:
- *circuit* (v0.5 lineage; Delta 7): reflection/transmission at a terminal pair, x = |Γ| = tanh η, u = |t|² = 1 − |Γ|², SWR = e^{2η} = G_new − 1 — "dopplerization is what the odds gauge is called when the port is a damped oscillator";
- *statistical* (07-19 Theorem P/C): a positive, unital, state-preserving map T with x² = Var(TY), u = E[T(Y²) − (TY)²]; readable iff u = MSE iff the record is sufficient;
- *arithmetic* (the functor treatment): the local Langlands datum of the object at v — the Satake doublet at unramified p, the archimedean parameter at ∞, the twist-determined datum at the ramified port — written in the coin chart.
The coin is p = (1+x)/2, q = (1−x)/2 (Will's construct; G_new = 1/q). **Residual capacity** is u: the continuous freedom left at the port. A **datum** is a port with u = 0 (x = 1, G = ∞, d_eff = 1); a **degree of freedom** is a port with u = 1 (x = 0, the fair coin). The budget x² + u = 1 *is* the interpolation between them — no new formalism is needed for the interpolation itself; the content is in which ports carry which.
Exact instance [T] (expedition §3): at the archimedean port the coin is the Layer-1 DHO of the radial equation, x² = ¼/λ, u = r²/λ. **Galois type ⟺ the archimedean port is a datum** (r = 0, u = 0); a generic tempered form has residual capacity u = r²/λ ∈ (0,1); the exceptional eigenvalues are over-budget. Finite ports [id, Delta 7's elliptic face]: the coin bias is the Satake angle, x_p = sin Δ_p, so u_p = |a_p|²/4 for unitary nebentypus; Galois type ⟹ the finite-port coins take values in a finite alphabet (the character table — 1A: u = 1; 2A: u = 0; 3A: u = ¼; 5A/5B: u = φ^{±2}/4); the converse is Sarnak's integrality conjecture, Chain S's open link. So the datum/freedom dichotomy is exactly the Galois-type/generic dichotomy, port by port.

## 2. Words and word length [T-cited; exact, unconditional for L(ρ̃) by Brauer]

Its **word length** is log p^k = log|𝔽_{p^k}|: the information of a k-letter word over the port's alphabet 𝔽_p; its **primitive length** is log p = the information of one symbol = the von Mangoldt weight. The Weil explicit formula for L(ρ̃) — meromorphic with functional equation by Brauer, hence the formula holds unconditionally — is then the port–word ledger:
